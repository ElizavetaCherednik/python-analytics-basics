# Python для аналитических задач

**Цель:** Показать владение Python на уровне, достаточном для решения учебных и прикладных аналитических задач.

Репозиторий создан по итогам прохождения хендбука **«Основы Python» от Яндекса** (курс пройден полностью).  
Код написан самостоятельно в процессе обучения и дополняется по мере изучения новых инструментов.

---

## Что здесь есть

| Папка | Что демонстрирует |
|-------|-------------------|
| `01_basics/` | Циклы, функции, списки, кортежи, рекурсия, lambda-выражения, генераторы |
| `02_classes/` | Основы ООП: классы, конструктор `__init__`, методы, атрибуты |
| `03_numpy/` | Работа с массивами: создание, индексация, срезы, векторизованные операции |

---

## Используемые технологии

- **Python 3.x**
- **NumPy** — массивы и векторизованные вычисления
- **Pandas** — табличные данные
- **math** — математические функции (стандартная библиотека)

Установка зависимостей:

```bash
pip install numpy pandas
```

## Текущий уровень

### Базовый Python
- Циклы (`for`, `while`, вложенные циклы)
- Функции (`def`, аргументы, `return`, именованные аргументы)
- Списки и кортежи (срезы, списочные выражения, обход, распаковка)
- Словари и множества
- Рекурсия
- Lambda-выражения, `map`, `filter`, `sorted` с ключами
- Генераторы (`yield`) и генераторные выражения
- Работа с файлами, исключения (`try/except`)

### ООП
- Классы, `__init__`, методы, атрибуты
- Базовое понимание магических методов

### NumPy
- Создание массивов (`array`, `arange`, `linspace`, `zeros`, `ones`)
- Индексация, срезы, булевы маски
- Векторизованные операции вместо циклов
- Агрегации (`sum`, `mean`, `min`, `max`)
- Изменение формы (`reshape`, `transpose`)

### Pandas
- `Series` и `DataFrame`
- Загрузка данных (`read_csv`), выбор столбцов и строк (`loc`, `iloc`)
- Фильтрация и `groupby`
- Обработка пропусков

### math
- `sqrt`, `log`, `exp`, `floor`, `ceil`
- Тригонометрия (`sin`, `cos`, `radians`, `degrees`)
- Константы `pi`, `e`
